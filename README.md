# COVID_PowerBI_Assignment

## COVID-19 Data: Analysis and Insights
### Project Overview
#### The primary goal of this project was to design a dashboard for analyzing and gaining insights from the provided COVID-19 dataset. The dashboard visualizes key trends, highlights patterns, and provides detailed hierarchical data.

Thought Process During Dashboard Creation
1.	Understanding the Data
o	Initial exploration revealed time-series data grouped by country and region, with both daily and cumulative metrics for cases and deaths.
2.	Choosing Appropriate Visualizations
o	Line charts were selected for time trends due to their ability to show continuous data.
o	Bar charts provided a clear comparison of countries and regions.
o	The choropleth map added geographic context, enhancing spatial understanding of case intensity.
3.	Data Aggregation and Smoothing
o	Moving averages were computed to smooth out noise in daily data, ensuring clearer trend identification.
o	Hierarchical summaries helped organize data effectively for region-wise drill-down analysis.
4.	Interactivity and Filters
o	A monthly filter was added to facilitate dynamic analysis of country-wise cases.
o	Date wise filter was added to see the covid evolution over as specific time period.
o	Hierarchy of WHO region and Country was added to analyse the intensity of covid Region and country wise.
